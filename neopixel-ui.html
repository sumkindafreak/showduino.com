NeoPixel FX

Immersive RGB Magic — From Haunt to Hero

Overview

Take full command of lighting with Showduino's NeoPixel engine. Build intense horror atmospheres, dynamic colour pulses, and thematic fades using intuitive UI controls — all synchronised to your timeline.

💡 FX Features

  • Group-based brightness and effect control
  • Real-time sliders for responsive editing
  • Custom mapped matrices (e.g. 9×8 serpentine)
  • Preview mode for testing patterns before deployment
  • Flicker, glow, pulse, graveyard, and custom horror effects
  • DMX integration for combined lighting rigs

🗺️ Layout & Mapping

The system supports visible-only pixel mapping, perfect for props like haunted lanterns or summoning tablets. Layouts can be non-rectangular and still look perfect with the mapping engine.
