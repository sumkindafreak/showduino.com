Modular Add-ons

Showduino supports external props and modules known as add-ons. These range from atmospheric lighting props like the Haunted Lantern to interactive puzzle devices like the R3 Terminal — all controllable from the GoreFX Timeline Editor.

🏮

Haunted Lantern (7-Pixel Jewel)

A compact NeoPixel Jewel prop with built-in horror lighting effects. Drop it into any set piece for instant atmospheric glow.

  • flickerEffect — organic candle flicker
  • glowEffect — steady haunted pulse
  • hellfireEffect — intense crimson flames
  • graveyardGlowEffect — slow eerie breathe
🖥️

R3 Terminal

Industrial escape room prop featuring 3 buttons, a magnetic lock, and full LED feedback. Designed for puzzle integration and operator control.

  • Console Flicker — boot-up animation
  • Shocking — voltage surge effect
  • Time Flicker — countdown glitch
  • Glitch Red — corrupted signal burst
  • Smoke Control — relay-triggered fog
🎞️

Timeline FX Support

All add-ons integrate with the GoreFX Timeline Editor. Drag and drop FX events onto prop-specific tracks with full control over timing, playback speed, and intensity.

  • Prop-specific track lanes
  • Trigger events with precise ms timing
  • Sync with audio & relay channels
  • Save & reload via HauntSync
🔧

Custom Prop Integration

Build your own add-ons using the Showduino firmware API. Any prop with an ESP32 or Arduino can register as a device and receive timeline commands.

  • Open serial command protocol
  • ESP-NOW wireless integration
  • Custom FX parameter mapping
  • Register via HauntSync portal
