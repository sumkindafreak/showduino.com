SHOWDUINO

Immersive Show Control System by GoreFX

Professional Arduino-based control system designed for haunted attractions, escape rooms, and interactive installations. Seamlessly orchestrate lighting, audio, relays, pixels, and environmental effects from one unified platform.

🎬 Launch Studio ☁️ Open HauntSync

Key Features

📱

Touchscreen Interface

Interactive ESP32 touchscreen menu with real-time brightness control, Bluetooth triggers, and intuitive icon-based navigation.

💡

NeoPixel Control

Advanced NeoPixel engine with group-based brightness adjustment, dynamic horror lighting effects, and custom pixel mapping.

🔌

Relay Management

Precise relay triggers for dynamic prop effects, environmental controls, and automated sequence execution.

📡

Wireless Control

Bluetooth and WiFi connectivity for remote control, ESP-NOW mesh networking, and cloud synchronisation via HauntSync.

🎵

Audio Integration

Dual I2S audio playback with synchronised timeline triggers, multi-track support, and real-time volume control.

��

Diagnostics

Real-time system monitoring with comprehensive self-test routines, temperature sensors, power monitoring, and I/O state checking.
