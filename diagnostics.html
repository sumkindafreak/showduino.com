Diagnostics

Because Even Monsters Need Maintenance

Overview

Stay one step ahead of the chaos. Showduino's diagnostics engine delivers real-time hardware feedback and scripted self-tests to ensure every haunt element is ready for action before the doors open.

📊 Live Data Checks

  • Bluetooth + WiFi connection status
  • SD card presence & health
  • Temperature + voltage readings (from Mega)
  • NeoPixel group brightness levels
  • Relay & input pin states
  • I2S audio channel status

🖱️ Manual Control

All diagnostics are triggered manually — no automatic polling to avoid CPU drag during show operation. Tap the test button whenever you need the truth about your system state.

Results are displayed with ✅ PASS / ❌ FAIL status per module.

🧪 Self-Test Mode

Launch a full self-test sequence from the Showduino menu. It checks all connections, toggles relays, queries inputs, and confirms visual and audio output — all with clear pass/fail feedback per subsystem.

  • Relay cycle test (toggle on/off)
  • NeoPixel colour sweep
  • Audio playback confirmation
  • Bluetooth ping check
  • WiFi connectivity verification
