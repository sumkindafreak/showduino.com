# 🚀 Showduino Website Deployment Package

## Quick Start (Choose One Method)

### ⚡ Method 1: Double-Click Deployment (Windows)

1. **Double-click** `DEPLOY-TO-GITHUB.bat` or `DEPLOY-TO-GITHUB.ps1`
2. Enter your GitHub repository path when prompted
3. Files will be copied automatically
4. Follow the on-screen instructions to push to GitHub

### 💻 Method 2: Manual Command Line

```bash
# Navigate to your GitHub repo
cd /path/to/showduino.com

# Copy all files from this folder
# Then run:
git add .
git commit -m "Update website with HauntSync and Studio"
git push origin main
```

### 🌐 Method 3: GitHub Desktop

1. Open GitHub Desktop
2. Select your repository
3. Copy all files from this folder to your repo folder
4. Commit and push
