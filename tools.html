CURRENT HARDWARE STACK

Built around
real roles.

The Showduino hardware stack follows the same architecture as the software: dedicated devices for operator control, communications, runtime authority and physical outputs.

PHYSICAL PRODUCT

The enclosure follows the architecture.

The current build puts the operator touchscreen, emergency control, service connections and P4-based runtime into a physical system that can be mounted, opened, wired and diagnosed like equipment.

Important: the touchscreen is the Director. It is not the authoritative Show Engine. The P4 remains responsible for runtime state and safety.
DIRECTOR

ESP32-S3 800×480 touchscreen

The Director is the operator-facing controller for live requests and system state.

  • RoleOperator requests and state display
  • Primary linkESP-NOW to Communications Controller
  • Runtime authorityNo — the P4 remains authoritative
COMMS CONTROLLER

Dedicated ESP32-S3 bridge

The Comms Controller transports wireless traffic to the P4 without making show decisions.

SHOW ENGINE

Waveshare ESP32-P4-Module-DEV-KIT

The P4 is the centre of the live runtime: state, safety, cue dispatch, timeline execution, local storage and Showduino system services.

REPAIRABLE BY DESIGN

What's inside Showduino?

Ordinary, replaceable development boards rather than a sealed custom-PCB controller. Each module has a specific role, service documentation and firmware. These are reference/vendor photographs; a few are representative of the board family rather than a verified photo of the fitted revision.

CORE · EXACT MODEL

Waveshare ESP32-P4-Module-DEV-KIT

P4 Show Engine, mounted in the main Showduino enclosure beneath the tilting touchscreen. Runs cues, storage, system audio, local lighting and the Emergency latch.

Replacement: same P4 board revision, reflash Show Engine, fit microSD/configuration, verify UART, safety and audio before use.

ESP32_MOS_X4 MOSFET Node

Four-channel low-voltage digital/PWM output module. The Showduino firmware is implemented; board mapping and physical outputs still need commissioning.

EXPANSION

I²C without turning the P4 into a wiring mess.

The P4 exposes a defined plug-in bus for supported I/O and PWM expansion hardware.

MCP23017

General-purpose digital I/O expansion.

PCA9685

Multi-channel PWM/servo-style expansion.

TCA9548A

I²C multiplexing for repeated addresses or separate branches.

Current scope note: DMX is deliberately not part of the current Showduino implementation plan. The present focus is relay, MOSFET, pixel, audio, storage and runtime.
