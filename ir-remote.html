IR Remote

Retro Control Meets Horror Tech

Overview

Take full control without touching the screen. Showduino's infrared remote system brings TV-style input to your haunt tech — ideal for prop operators, hidden tech panels, or wireless puzzle triggers.

📺 Remote Capabilities

  • Navigate menu items with arrow + OK buttons
  • Trigger effects, sequences, or system actions wirelessly
  • Numeric entry for quick access to hidden features
  • Compatible with standard 38kHz IR receivers
  • Multi-button macro support

⇧ SHIFT Functionality

Support for capital letters and symbols is built in using a SHIFT toggle on the remote. This allows full WiFi password input, Bluetooth naming, and more — all without a physical keyboard.

Works seamlessly with the Showduino touchscreen UI for hybrid input.

🎭 Perfect for Escape Rooms

IR remote control is ideal for operators running shows from behind the scenes. Embed control into set pieces, puzzle props, or wearable gear. Trigger sequences from anywhere in the room without breaking immersion.

🔜 Planned Upgrades

  • Custom remote profiles with learnable buttons
  • Configurable trigger sequences per button
  • Infrared recording & playback for puzzle integration
  • Long-press actions for alternate command modes
