THE CURRENT ARCHITECTURE

Four jobs. Clear responsibility.

The current Showduino system is deliberately split so operator controls, transport, show decisions and physical outputs cannot accidentally become the same job.

01 / DIRECTOR

ESP32-S3 Director

The 800×480 touchscreen is the operator desk. It requests actions, displays state and keeps the live controls clear.

ESP-NOW →
02 / TRANSPORT

S3 Comms Controller

A dedicated bridge between wireless devices and the P4. It transports messages; it does not make show decisions.

UART 115200 →
03 / AUTHORITY

ESP32-P4 Show Engine

The runtime authority for state, timeline, safety, cues and emergency behaviour. The show lives here.

COMMANDS →
04 / ACTION

Specialist Nodes

Relay, MOSFET, pixel and audio nodes perform commanded work and report results back to the system.

ACTUATE + REPORT
Studio creates it. Director operates it. P4 runs it. A live production does not need the browser, internet or touchscreen to keep the timeline alive.
PHYSICAL PRODUCT

The enclosure follows the architecture.

The current controller is built around practical operation and serviceability. This first pass uses a lightweight schematic while the final product photography is added later.

Operator hardware

Adjustable touchscreen Director

The interface is a real physical operator surface, not the thing responsible for continuing show execution.

Physical safety

Emergency control stays obvious

The dedicated emergency control is deliberately separated from touchscreen UI actions and normal show cues.

Serviceability

Connections stay accessible

Pluggable terminals, USB, Ethernet and antennas are treated as equipment interfaces rather than development-board clutter.

PIXEL SYSTEM

Segmented in the show. Unmistakable in an emergency.

Pixel lines can be divided into logical segments for show effects, while the emergency state overrides every line and drives every pixel bright white.

SHOW MODE · EXIT SIGN SEGMENTSexample: pixel 0 / 10 / 20 green

The same physical line can remain visually useful during a production while preserving logical emergency-sign groupings.

EMERGENCY OVERRIDEall pixels · bright white

Emergency state wins over show effects. The visual override is system-wide, not limited to a decorative emergency strip.
