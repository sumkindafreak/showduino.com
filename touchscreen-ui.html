Touchscreen

Intuitive FX Control at Your Fingertips

Overview

The Showduino touchscreen interface brings a sleek and powerful control panel to life using the ESP32 display board. Navigate menus, control brightness, launch diagnostics, and more — all with glowing tactile feedback.

📱 Key Features

  • Animated menu transitions for smoother UX
  • Brightness sliders for TFT display and NeoPixels
  • Volume control for MP3 players A & B
  • Bluetooth & WiFi status indicators
  • Self-test initiation directly from the screen
  • Long-press detection for advanced options

✨ Interface Enhancements

All buttons feature glowing visual feedback. Long-press detection enables advanced options menus for power users. The UI runs at smooth frame rates even on the ESP32's single-core display thread.

Designed for the ESP32 2.8″ SPI TFT display (ILI9341 driver).

🔜 Future Upgrades

  • Dark mode toggle via settings menu
  • UI sound toggle (beeps, FX triggers)
  • Icon-based menu categories
  • Real-time pixel previews during editing
  • Gesture support for compatible displays
