SHOWDUINO

Immersive Show Control System

Professional Arduino-based control system designed to manage immersive horror experiences, escape rooms, and interactive installations. Combining multiple microcontrollers to deliver seamless control of lighting, audio, and environmental effects.

🎬 Launch Studio ☁️ Open HauntSync

Key Features

📱

Touchscreen Interface

Interactive ESP32 touchscreen menu with real-time brightness control, Bluetooth control, and intuitive icon-based UI.

💡

NeoPixel Control

Advanced NeoPixel displays with group-based brightness adjustment, dynamic lighting effects, and seamless DMX integration.

🔌

Relay Management

Precise relay triggers for dynamic effects, environmental controls, and automated sequence execution.

📡

Wireless Control

Bluetooth and WiFi connectivity for remote control, ESP-NOW mesh networking, and cloud synchronization.

🎵

Audio Integration

I2S audio playback with synchronized timing, multi-track support, and seamless show integration.

🔍

Diagnostics

Real-time system monitoring with comprehensive diagnostics, temperature sensors, power monitoring, and I/O testing.
