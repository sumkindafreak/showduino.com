LOCAL HARDWARE ACCESS

Connect to your Communications S3

Your home network makes the local console accessible without joining the Showduino access point. Enter the S3's LAN IP (not the P4's IP). This remembers an address; it does not silently connect to hardware.

Open Local Console

Use the S3's STA/LAN IP from your router or the Communications diagnostics screen. Phone/computer must be on the same local network.

To install a show: open Website Studio → export a .shdo → open the local console → Productions → Persist to SD. The P4 checks and stores the show without starting it.

LOCAL-FIRST

Project management is not the runtime

HauntSync can help organise projects and hardware, but a running show remains the responsibility of the P4 Show Engine. Cloud availability must never become a live-show requirement.
